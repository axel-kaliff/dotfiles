# ADHD response shaping: mechanism choice and upstream evidence
- Question: Where does an always-on response-shape ruleset belong in Claude Code, and how good is the evidence behind ayghri/i-have-adhd?
- Status: verified
- Updated: 2026-09-09

## Summary
`claude/.claude/output-styles/adhd.md` is a hand-rewrite of the `i-have-adhd` skill (ayghri/i-have-adhd, MIT, 31k stars) as a custom output style rather than a skill or an always-on SessionStart hook. Output styles are the documented mechanism for a response format wanted every turn; they modify the system prompt, Claude Code re-reminds the model of the style during the conversation, and `keep-coding-instructions: true` preserves the built-in software-engineering instructions. That mechanism replaces upstream's entire "Persistence" section, its three always-on hook scripts, and its flag file. Enable per session in `/config` under Output style; it is deliberately not set as a default, because style directives compete for the same instruction budget as CLAUDE.md's rules.

## Findings — 2026-09-09
- Output styles are canonical and current: file at `~/.claude/output-styles/*.md`, frontmatter `name` / `description` / `keep-coding-instructions` / `force-for-plugin`, selection saved to `.claude/settings.local.json`. The standalone `/output-style` command was deprecated in v2.1.73 and removed in v2.1.91; use `/config`. Terminal reads style files at startup, so edits need a restart (source: https://code.claude.com/docs/en/output-styles.md, Sep 2026; local install 2.1.266)
- A built-in `Concise` style (v2.1.237+) already covers roughly a third of the upstream ruleset — leads with the result, skips preamble and narration, still explains in full on request, and keeps error reports, security warnings, and destructive-action confirmations complete. It is the zero-maintenance alternative and the right A/B baseline for the custom style; what it does not do is restate progress, number steps, name a next action, or give time estimates, which is where upstream's own eval shows the largest gains (source: same doc; evals/RESULTS.md)
- Upstream's eval is better run than most and still weak: blind A/B with digest-seeded condition permutation, isolated runner (`--ignore-user-config`), pinned model, 14 cases x 3 trials, weighted 1-5 rubric. Result +0.427 weighted (largest gains `multi-step-progress` +2.53 and `error-report` +2.40), but self-judged by the same model family, per-case SD up to 0.95, and its own release gate FAILED on 3 blocking findings (source: evals/RESULTS.md, evals/rubric.md, 2026-08-02)
- Two upstream regressions drove content changes here. `partial-success` regressed -0.63 because "cause, then fix" pressures a confident cause onto thin evidence — the rewrite says name a cause only when the evidence identifies it, which is also the CLAUDE.md debugging rule. Issue #96 (15 comments) found "cap lists at 5" read as licence to discard items; the rewrite forbids dropping an item to reach five (source: evals/RESULTS.md; github.com/ayghri/i-have-adhd issues #96, #98)
- The upstream plugin was not installed, and its install path is the reason. The only Claude Code paths offered are marketplace plugin install plus a `~/.claude/.i-have-adhd-always` flag file read by a SessionStart hook; that registration has open reliability issues — #61/#62 hooks never loaded, #129 silent no-op when `CLAUDE_PLUGIN_ROOT` is unset, #70 Windows shell incompatibility (source: INSTALL.md, hooks/hooks.json, repo issues)
- Independent commentary is skeptical and there is no third-party measurement. HN 49610631: conciseness instructions hold "a few turns at most"; one commenter tested output styles and found they "very much don't force Claude to speak succinctly"; another questions 8.7k lines across 59 files behind a 140-line prompt. Issue #112 reports a severe regression on Grok 4.6, unresolved — consistent with the digest's principle 13, re-ablate per model generation (source: news.ycombinator.com/item?id=49610631; issue #112)
- Rewrite shape, per docs/agent-harness-research.md: 10 rules, 6 exceptions and 8 example pairs became 10 prohibitions each ending in a Why (principles 3 and 5), no examples, ~25 lines of instruction against upstream's ~170. Principle 4 is the binding constraint — an always-on style spends the same instruction budget as CLAUDE.md, and the skills evidence has compact bodies at +19.0 against comprehensive at +0.7.
